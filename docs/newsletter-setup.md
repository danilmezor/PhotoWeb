# Newsletter Setup

_Last updated 2026-06-09. The newsletter runs on **MailerLite** (free plan) with a custom on-site subscribe form that posts directly to MailerLite's public endpoint — no backend, no server secret. Sending is **manual broadcasts**; an RSS feed is generated for optional future automation._

## Architecture (why it's built this way)
The site is a static prerendered SPA on Vercel with no backend, so a managed ESP owns the list, double opt-in, unsubscribe, compliance, and delivery. We only ship the form + an RSS feed. See `seo-discovery-strategy.md` for why an owned list matters.

- **From name:** `Danil Zanozin Photography` (what subscribers see — keeps the brand even though the address differs).
- **From address:** `newsletter@danilzanozin.com` — needs **no mailbox**; it's authenticated via DNS.
- **Authenticated sending domain:** `danilzanozin.com` (DNS on Vercel).
- **Reply-To:** the working **@traciora.com** mailbox (so replies actually reach an inbox; Reply-To needs no authentication).

## Code wiring (done)
- `src/components/NewsletterForm.jsx` — custom form, `no-cors` POST of `fields[email]` (+ `ml-submit`, `anticsrf`) to the endpoint above. Reads `VITE_MAILERLITE_ACCOUNT_ID` / `VITE_MAILERLITE_FORM_ID`.
- Placed in `src/components/Footer.jsx` (variant `inline`, site-wide) and `src/pages/BlogPost.jsx` (variant `card`, end of each post).
- RSS feed `public/feed.xml` generated by `scripts/generate-seo-files.mjs` (blog posts only); discovery `<link rel="alternate">` in `index.html`.
- Env vars live in `.env.local` (gitignored). **Must also be set in Vercel** → Project → Settings → Environment Variables → redeploy.

## Sending a new post/gallery announcement
Write a **broadcast** (campaign) in MailerLite to the Newsletter group when you publish. Personal note + a few images. (Optional later: enable an RSS campaign pointed at `https://danilzanozin.com/feed.xml` to auto-send on new blog posts — code already emits the feed.)
